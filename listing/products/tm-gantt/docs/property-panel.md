# Configure the chart

In **Data mapping**, choose one to eight dimensions and two to twelve measures. Set one dimension as the **Row level**. Dimensions above it make collapsible groups; dimensions below it separate Activity instances on the same row. Assign measures to the required **Activity start** and **Activity end** roles. Optional roles include **Display label**, **Progress**, **Sort value**, **Color value**, **Activity type**, and **Tooltip value**.

Use **Formatting** to set the time range, text size, labels, tooltips, Activity table, colors, and legend. The table can show up to six additional columns. The **Styling** tab is Qlik's native panel for the title, subtitle, footnote, background, border, and shadow. Tm Gantt uses the General background color for its chart surface and keeps readable text contrast.
