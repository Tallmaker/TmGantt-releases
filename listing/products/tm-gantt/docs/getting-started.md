# Add a schedule

Add Tm Gantt to a Qlik Cloud sheet, then bind the data that defines your schedule.

1. Add one to eight dimensions. Choose a **Row level dimension** in **Data mapping**. Dimensions above it become collapsible groups; dimensions below it distinguish Activities on the same row.
2. Add two to twelve measures. Assign the **Activity start** and **Activity end** roles to the measures that hold those dates.
3. Check **Configuration checks** in Data mapping. It lists any missing dimensions, row level, or required measure roles.
4. Add optional roles such as **Display label** or **Progress**, or show the Activity table with extra columns.

Activities need both a valid start and end date to appear on the timeline.
