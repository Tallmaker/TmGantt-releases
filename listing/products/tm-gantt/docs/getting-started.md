# Add a schedule

Add Tm Gantt to a Qlik Cloud sheet, then bind the data that defines your schedule.

1. Add one to eight dimensions. In **Data mapping**, choose a **Row level dimension**. Dimensions above it become collapsible groups; dimensions below it distinguish Activity instances on the same row.
2. Add two to twelve measures. Assign **Activity start** and **Activity end** to the measures that hold those dates.
3. Read **Configuration checks** in Data mapping. It lists missing dimensions, the Row level, or required measure roles.
4. Add optional roles such as **Display label** or **Progress**, or show the Activity table.

Each Activity needs a valid start and end date to appear on the timeline.
